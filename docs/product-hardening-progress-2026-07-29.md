## 已完成

1. 下载队列会话恢复
   - 队列状态原子落盘，启动时恢复未完成任务。
   - 下载中、解析中和合并中的任务重启后恢复为暂停，避免意外自动联网。
   - 持久化白名单不包含 Cookie、令牌、取消对象和原始错误详情。

2. 下载前安全检查
   - 检查输出目录、写权限、磁盘余量和预估文件大小。
   - 单下载和批量下载都已接入。

3. 重复下载检测
   - 规范化链接并移除常见追踪参数。
   - 对照下载历史和本地文件；单任务确认，批量任务可统一跳过重复项。

4. 首次运行就绪流程
   - 缺少组件时不再静默安装。
   - 由用户点击“安装并继续”，并记录首次运行完成状态。

5. 失败恢复与诊断
   - 下载失败按认证、代理、网络、工具、存储、限流等类型给出恢复入口。
   - 设置页可生成脱敏诊断包。

6. 用户数据备份与恢复
   - 备份历史数据库和非敏感设置。
   - 明确排除 Cookie、浏览器登录会话、Telegram 凭据和含凭据代理。
   - 恢复前校验大小、SHA-256 和 SQLite 完整性，并保留失败回滚路径。

7. 桌面长任务体验
   - 活跃下载期间可阻止系统休眠。
   - 支持最小化到托盘、打开/退出菜单和完成/失败通知。
   - 托盘实现使用 WPF 与 Windows Shell API，没有引入 WinForms 依赖。

8. 后台更新维护
   - 每 24 小时静默检查一次，只提示，不自动安装。
   - 清理过期安装包和未完成的下载临时文件。

9. 历史文件生命周期
   - 历史页删除按钮右键菜单支持“同时删除本地文件”。
   - 删除范围限制在允许的下载目录内。
   - 设置页可扫描并清理文件已不存在的历史记录；没有文件路径的旧记录不会被误删。

10. 已有界面细节
    - 批量下载队列行横向铺满，进度条按统一列对齐。
    - 本轮只保留已经完成的 UI 修改，没有纳入中止任务的半成品。

11. 全局下载限速
    - 配置版本升级至 v4，设置页支持输入全局 `KB/s` 上限，`0` 表示不限速。
    - yt-dlp 下载统一加入 `--limit-rate`，配置迁移、范围归一化、自动保存和备份白名单均已覆盖。

12. 定时下载与重启恢复
    - 单下载页支持设置本地计划时间、校验过去或无效时间，并可在计划执行前取消。
    - 计划任务使用可取消延时，到点进入现有下载管线；支持持久化、重启恢复、逾期启动、重新计划和队列筛选。

13. 动态源格式选择
    - 从 yt-dlp 解析结果展示真实分辨率、帧率、容器、编码、预估大小和格式 ID。
    - 具体视频源流自动匹配音频，选择结果随队列持久化，并用于下载参数和磁盘预检。

14. 发布供应链
    - GitHub Actions 支持可选 Authenticode 签名；Secrets 缺失时明确发布未签名产物，配置不完整时阻止发布。
    - 使用 Microsoft SBOM Tool 4.1.5 生成 SPDX 2.2，固定 SHA-256 已由官方 API 与微软 SPDX 清单双重核对。
    - 使用 `actions/attest@v4` 生成来源证明和 SBOM 证明，并将 SBOM 加入 Release 资产。
